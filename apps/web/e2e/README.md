# E2E Tests (Playwright)

## Commands
- `npm run e2e`
- `npm run e2e:ui`
- `npm run e2e:report`

## Environment
- `BASE_URL` (optional): defaults to `http://127.0.0.1:3000`

## Notes
- Start the app first (`npm run dev` or `npm run start`).
- Tests attach trace/screenshot/video on failure.
- Tests fail on severe browser JavaScript errors.
